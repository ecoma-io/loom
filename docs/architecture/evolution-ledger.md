## Program-level constraints

Carried from the operating model and the repository's own law; every work
item inherits them.

- One public npm package (`@ecoma-io/loom`); internal manifests stay private.
- Dependencies flow toward foundations; the facade is a sink; the edge set is
  a DAG.
- Consumer-shaped artifacts (templates, docs site, E2E) reach the facade and
  stylesheets only, with the disclosed conformance-route exception.
- The layout engine stays internal, pure, and out of the published API; a
  runtime renderer appears only when a real, measurable use case exists.
- Gates must be able to fail: every new enforcement rule ships with a
  negative/mutation test.
- Browser evidence runs in CI; local validation is lint + typecheck + build +
  archkeep (repository working agreement).
- WCAG AA (the `WCAG_TAGS` set) is inviolable: coverage is never traded for
  speed, and an exclusion needs a named criterion plus a cause outside this
  repository's reach.
